HART · Highway Addressable Remote Transducer

让一根 4–20 mA 线上
同时流动测量值与设备信息

02 · 信号与接线

先让回路正确，再谈通信

现场基础

FSK 为什么不扰动模拟量？

HART 有线数字信号采用 Bell 202 FSK：逻辑 1 与逻辑 0 由不同频率表示。FSK 信号的平均值为零，因此数字通信叠加在电流环上时，不改变 4–20 mA 模拟信号的直流平均值。

逻辑 1 · Mark1200 Hz
逻辑 0 · Space2200 Hz

“250 Ω”是常见起点，不是盲目规则

通信器需要在回路阻抗上检测交流信号。约 250 Ω 常见于实验接线，但最终应核对电源余量、仪表最低工作电压、回路总阻抗、隔离栅与厂商手册。

电压余量Vsupply − Iloop × Rtotal ≥ Vdevice,min

03 · 帧与通信

一帧 HART 消息里有什么？

先看懂边界、地址、命令和校验，原始 Trace 就不再是一串陌生 HEX。

协议基础

Command1 byte或 Cmd 31 扩展
Byte count1 byte后续字节数

请求帧不含 Status；Byte Count 仅表示请求 Data 的字节数。 响应帧包含 2 个 Status 字节；Byte Count 包含 Status 与响应 Data。
01

前导码 Preamble

连续 0xFF 帮助接收端建立载波同步。常见请求使用 5 个；设备身份响应会报告其要求，主站应按设备要求处理。

02

短帧与长帧

发现设备时常用短地址发送 Cmd 0；取得设备身份后，后续事务通常使用由设备类型与唯一标识组成的长地址。

03

状态字节

响应帧在 Byte Count 后带两个状态字节。第一字节可能是通信错误摘要或命令响应码，第二字节为设备状态；不能只看是否“有回包”。

04

XOR 校验

从 Delimiter 开始到 Data 最后一个字节逐字节异或，不包含 Preamble 和 Checksum 自身。它能发现多类传输错误，但不是加密或身份认证。

字符格式1 + 8 + 1 + 1 = 11 bitStart + Data + Odd parity + Stop
字符时间约 9.167 ms11 bit ÷ 1200 bit/s
起始检测FF FF + Delimiter官方建议请求使用 5 个 0xFF 前导码

More Status Available 被置位：继续读取 Cmd 48，并按设备修订、EDD / FDI 和厂商文档解释附加状态。

主站角色

传统有线 HART 支持 Primary Master 与 Secondary Master。两个主站都必须遵守介质访问与时序规则，不能把串口请求无节制地并发发送。

轮询地址

地址 0 常用于点对点设备。多点模式下多个现场设备共享一对导线并以不同轮询地址通信；可用范围与回路电流行为取决于协议版本和设备实现。

Burst 模式

Burst 是可选能力：设备可周期性发布某个命令的响应，无需主站每次发起。主站和 I/O 系统也必须支持正确接收与配置。

05 · modusignal 实操

一次可靠会话的推荐顺序

先用只读命令确认链路与设备身份，再逐步增加变量读取和配置操作。

进入 HART 工作台
  1. 01

    搭建并检查回路

    确认外部供电、极性、负载、电压余量与现场许可；将 HART 通信器并联到合适位置。

    不要假设 USB 会给回路供电
  2. 02

    连接串口

    选择 HARTLink 或兼容接口。标准有线 HART 串口参数为 1200 baud · 8O1。

    8 数据位 · 奇校验 · 1 停止位
  3. 03

    搜索与建立身份

    先尝试地址 0 的 Cmd 0；未知地址时扫描。收到身份后使用长地址继续通信。

    先身份，后参数
  4. 04

    读取变量与状态

    用 Cmd 1 读取 PV，或 Cmd 3 读取动态变量；同时检查响应码、设备状态与工程单位。

    “收到响应”不等于“命令成功”
  5. 05

    配置前先读后写

    记录原值，预览请求，确认影响范围后执行写操作；随后重新读取对应参数独立验证。

    保留原始 TX / RX 与变更记录

06 · 排障手册

从物理层往上查，不要先猜命令

大多数 HART 问题可以沿“回路 → 串口 → 帧 → 地址 → 命令 → 设备状态”的顺序快速收敛。

完全没有响应超时 · RX 空白 · 搜索不到设备
  1. 用万用表确认回路电流与仪表供电。
  2. 确认通信器并联位置与回路阻抗，不要只检查 USB。
  3. 核对串口是否为 1200 8O1，且没有被其他软件占用。
  4. 先试地址 0，再扫描可能的轮询地址。
  5. 若有示波器，检查是否存在主站 FSK 信号及设备回波。
能看到字节，但校验或帧解析失败Checksum · Parity · Framing · Gap
  1. 确认奇校验而不是常见的 8N1。
  2. 检查是否误把通信器封装、时间戳或换行符当作 HART 原始字节。
  3. 校验范围从 Delimiter 到 Data 末字节，不包含 Preamble。
  4. 检查接地、隔离、噪声与过长支线；保存原始 HEX 便于比对。
Cmd 0 成功，后续命令失败长地址 · 修订 · 前导码 · 不支持
  1. 从 Cmd 0 响应正确组合长地址，不要继续盲用短地址。
  2. 使用设备报告的前导码数量。
  3. 根据设备 HART 修订选择命令；可选命令不一定实现。
  4. 解析响应码和设备状态，区分“不支持”“忙”“写保护”和通信错误。
数值不合理或单位为空Float · Unit Code · Variable mapping
  1. HART 浮点通常按网络字节序解析，先检查字节偏移。
  2. 工程单位来自 Common Tables 的 Unit Code，不应凭数值猜单位。
  3. 确认读到的是 PV 还是某个 Device Variable，并检查分类与状态。
  4. 核对缩放/偏移是否由调试工具额外应用。
写入后设备行为异常量程 · 固定电流 · 地址 · 校准
  1. 立即停止重复写入，读取设备状态与相关参数。
  2. 检查是否仍处于固定电流或校准模式。
  3. 按变更记录恢复原值，并重新读取确认。
  4. 涉及控制或安全功能时，按现场 MOC / SIS 程序升级处理。

07 · 术语表

常见缩写，一次说清

PV
Primary Variable主过程变量，通常映射到 4–20 mA。
SV / TV / QV
Secondary / Tertiary / Quaternary第二、第三、第四动态变量。
FSK
Frequency Shift Keying以不同频率表示数字状态的频移键控。
DD / EDD
Device Description用 EDDL 描述设备参数、菜单、方法与命令语义。
FDI
Field Device Integration现代设备集成包技术，可包含 UID、EDD 等内容。
Burst
周期发布模式现场设备主动重复发布某个命令的响应。
Polling Address
轮询地址主站在共享链路上选择现场设备使用的短地址。
HART-IP
HART over IP在 IP 网络上保留 HART 应用层语义的通信技术。

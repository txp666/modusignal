串口设备由 GUI 唯一持有

不止是收发窗口

从一次连接，走到完整测试流程

常用功能保持顺手，复杂能力按需展开。无论临时看日志，还是搭建可重复的设备测试，都不需要切换工具。

01

清晰的串口终端

独立配置收发编码，支持文本、HEX、混合显示、搜索过滤、时间戳、自动断帧与多标签会话。

02

协议与校验工具

用协议模板拆解帧结构，内置 Modbus RTU 与常见 CRC、LRC、XOR、SUM8 计算及发送追加。

03

从宏命令到 AI 工具

内置宏和 JavaScript 处理桌面自动化；机器可读 CLI 与 MCP 把同一套能力开放给脚本、测试和 AI。

04

高性能实时绘图

从分隔值、键值对或 JSON 中提取多通道数字，以高性能实时曲线呈现并导出 CSV；CLI/MCP 也可直接打开和配置曲线。

05

面向现场的发送工具

常用包、发送历史、循环发送、自动应答和分块文件发送覆盖调试现场的高频操作。

06

完整记录与恢复

自动日志支持 TXT、CSV、BIN 与滚动存储；会话参数、规则和测试配置可在下次启动时恢复。

真实软件界面

熟悉的串口操作，放进更安静的工作区

连接配置和接收选项留在左侧，搜索、统计与终端记录集中在主区域，发送输入始终触手可及。浅色、深色和系统主题均可切换。

  • 扫描端口并显示描述、厂商、VID / PID 与序列号
  • RX / TX 统一记录，实时显示流量、速率和连接时长
  • 简体中文与 English 可即时切换，无需重启
